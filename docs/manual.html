1Требования и установкаRequirements and installation

OPEN работает на Windows 10 и Windows 11 (64-бит). Для работы нужны права администратора: без них нельзя менять системные настройки и считывать кадры игры.

  • Скачайте OPEN-Setup с сайта или со страницы релизов на GitHub.
  • Запустите установщик, выберите язык и примите пользовательское соглашение.
  • После установки OPEN запустится сам. Windows покажет запрос контроля учётных записей: нажмите «Да».

Windows SmartScreen или антивирус могут предупредить о неизвестной программе: оптимизаторы меняют реестр и просят права администратора. Скачивайте OPEN только с официального сайта или GitHub.

Новая версия ставится поверх старой, настройки и профили сохраняются.

OPEN runs on Windows 10 and Windows 11 (64-bit). It needs administrator rights: without them it cannot change system settings or read game frames.

  • Download OPEN-Setup from the website or the GitHub releases page.
  • Run the installer, pick a language and accept the Terms of Use.
  • OPEN starts by itself after installation. Windows shows a User Account Control prompt: click Yes.

Windows SmartScreen or your antivirus may warn about an unknown program: optimizers edit the registry and ask for administrator rights. Download OPEN only from the official website or GitHub.

A new version installs over the old one, and your settings and profiles are kept.

2Первый запускFirst launch

При первом запуске OPEN спрашивает язык интерфейса, а затем открывает окно «Авто-настройка под ваш ПК». OPEN определяет видеокарту, процессор, память и версию Windows и предлагает подходящий набор твиков с пояснением к каждому.

  • Снимите галочки с того, что вам не нужно.
  • Нажмите «Применить выбранное» или «Пропустить», если хотите настроить всё вручную.
  • Отметка «Не показывать при запуске» убирает окно. Открыть его снова можно в «Настройках».

Перед первыми изменениями создайте точку восстановления Windows: вкладка «Система», кнопка «Создать точку».

После обновления OPEN при первом запуске новой версии твики возвращаются к исходным настройкам Windows, а затем снова предлагается авто-настройка. Так новая версия начинает с чистого состояния.

On first launch OPEN asks for the interface language and then opens the Auto-setup for your PC window. OPEN detects the graphics card, processor, memory and Windows version and suggests a suitable set of tweaks with an explanation for each.

  • Untick anything you don't want.
  • Click Apply selected, or Skip if you'd rather set everything up yourself.
  • Ticking Don't show at startup hides the window. You can open it again in Settings.

Before making any changes, create a Windows restore point: the System tab, Create restore point button.

After an update, the first launch of the new version returns tweaks to the original Windows settings and offers auto-setup again. This way every version starts from a clean state.

3ГлавнаяHome

Главная нужна, чтобы оптимизировать систему за одно нажатие.

  • «Оптимизировать всё» применяет все твики, подходящие вашему железу. Перед каждым изменением OPEN сохраняет исходное значение.
  • «Откатить всё» возвращает все исходные значения.
  • Карточки показывают профиль производительности, число активных твиков, есть ли права администратора, видеокарту и запущенную игру.
  • «Игровой оверлей» показывает и скрывает счётчик FPS поверх игры. Горячая клавиша по умолчанию Alt+F11.

Home lets you optimize the system in one click.

  • Optimize all applies every tweak that suits your hardware. OPEN saves the original value before each change.
  • Revert all restores every original value.
  • The cards show the performance profile, the number of active tweaks, whether OPEN has administrator rights, the graphics card and the running game.
  • Game overlay shows or hides the FPS counter on top of the game. The default hotkey is Alt+F11.

4ОптимизацияOptimization

Здесь каждый твик включается и выключается отдельно. Твики разбиты на группы: Windows и планировщик, видеокарта, NVIDIA, питание, сеть, мышь и клавиатура. Под каждым твиком написано, что он делает.

  • Переключатель включает твик, повторное нажатие возвращает исходное значение.
  • «Включить всё» и «Выключить всё» действуют на весь список.
  • Серые твики недоступны на вашем железе, например настройки NVIDIA без видеокарты NVIDIA.
  • Твик, который вы выключили вручную, автоматика больше не включает.

Некоторым твикам нужна перезагрузка, это указано в их описании.

Here every tweak is turned on and off separately. Tweaks are grouped: Windows and scheduler, graphics card, NVIDIA, power, network, mouse and keyboard. Each tweak has a description of what it does.

  • The switch turns a tweak on, and turning it off restores the original value.
  • Enable all and Disable all act on the whole list.
  • Grey tweaks are unavailable on your hardware, for example NVIDIA settings without an NVIDIA card.
  • A tweak you turned off by hand is never turned back on by automation.

Some tweaks need a restart; their description says so.

5ПресетыPresets

Пресет решает, что OPEN делает с конкретной игрой, когда она запущена. Для каждой игры из списка выберите один из вариантов:

  • «Киберспорт»: максимум FPS и минимальная задержка для соревновательных игр.
  • «Баланс»: подходит большинству игр.
  • «Качество»: для тяжёлых одиночных игр, где важна картинка.
  • «Выключен»: OPEN ничего не делает с этой игрой.

Пресет применяется автоматически, если в «Настройках» включена «Авто-оптимизация при запуске игры».

A preset decides what OPEN does with a particular game while it runs. For each game in the list, pick one option:

  • Esports: maximum FPS and minimum latency for competitive games.
  • Balanced: suits most games.
  • Quality: for demanding single-player games where visuals matter.
  • Off: OPEN does nothing with this game.

The preset is applied automatically if Auto-optimize when a game starts is on in Settings.

6ИгрыGames

Вкладка меняет настройки внутри самих игр: CS2, Dota 2, Deadlock, Apex Legends, Rust, Fortnite и GTA V RP (Majestic RP, GTA5RP). Для каждой игры видно, установлена ли она и что сейчас настроено.

  • «Опции запуска Steam»: пропуск заставки и снятие лимита FPS. Ваши собственные опции не трогаются, «Откатить» возвращает то, что стояло до OPEN. Меняются при закрытом Steam.
  • «Рендер Vulkan» для Dota 2 и Deadlock: переключатель, чтобы сравнить, что быстрее на вашем железе.
  • «Видеонастройки игры» для Apex Legends, Fortnite и GTA V RP: тени, сглаживание и эффекты на минимум. Разрешение, текстуры и дальность прорисовки не меняются. Меняются при закрытой игре.
  • «Текстуры под видеопамять» для Fortnite: качество текстур подбирается под объём памяти видеокарты.
  • «Автопилот»: при запуске игры OPEN сам применяет её профиль и сообщает об этом уведомлением.

Игра записывает свои настройки при выходе. Если поменять их при запущенной игре, она перезапишет файл. Поэтому OPEN просит закрыть игру или Steam перед изменениями.

This tab changes settings inside the games themselves: CS2, Dota 2, Deadlock, Apex Legends, Rust, Fortnite and GTA V RP (Majestic RP, GTA5RP). For each game you can see whether it's installed and what's currently set.

  • Steam launch options: skip the intro and remove the FPS limit. Your own options aren't touched, and Revert restores what was there before OPEN. Changed while Steam is closed.
  • Vulkan renderer for Dota 2 and Deadlock: a switch to compare which is faster on your hardware.
  • Game video settings for Apex Legends, Fortnite and GTA V RP: shadows, anti-aliasing and effects to minimum. Resolution, textures and view distance stay. Changed while the game is closed.
  • Textures for video memory in Fortnite: texture quality is picked to fit your graphics memory.
  • Autopilot: when a game starts, OPEN applies its profile by itself and lets you know with a notification.

A game writes its settings when it exits. If you change them while it runs, it overwrites the file. That's why OPEN asks you to close the game or Steam before making changes.

7Настройки игры вручнуюEditing game settings by hand

У CS2, Apex Legends, Fortnite и GTA V RP в карточке игры есть кнопка «Настройки игры». Она открывает все параметры из файла настроек игры.

  • Известные параметры показаны с понятными названиями: тени, трава, сглаживание. Остальные видны, если отметить «Все параметры».
  • Найдите параметр через поиск, впишите значение, например 0 для теней, и нажмите «Сохранить».
  • Меняются только изменённые строки, остальной файл остаётся как был.
  • Перед первой правкой OPEN сохраняет копию файла. «Вернуть исходный файл» восстанавливает её.
  • «Отменить правки» сбрасывает несохранённые изменения, «Папка файла» открывает файл в проводнике.

Если файл не найден, запустите игру хотя бы раз и выйдите из неё: она создаст файл настроек.

CS2, Apex Legends, Fortnite and GTA V RP have a Game settings button on their card. It opens every setting from the game's settings file.

  • Known settings are shown with clear names: shadows, grass, anti-aliasing. The rest appear when you tick All settings.
  • Find a setting with the search box, type a value, for example 0 for shadows, and click Save.
  • Only the changed lines are written; the rest of the file stays as it was.
  • OPEN keeps a copy of the file before the first edit. Restore original file brings it back.
  • Discard edits drops unsaved changes, and File folder opens the file in Explorer.

If the file isn't found, launch the game at least once and exit: it will create its settings file.

8Серверы и пингServers and ping

Блок «Серверы и пинг» на вкладке «Игры» помогает играть на ближайших серверах.

  • Выберите свою страну. OPEN покажет, какой регион выбирать в Dota 2, Deadlock, Fortnite, Apex Legends и Rust.
  • «Проверить пинг» измеряет пинг до серверов Valve прямо с вашего компьютера и показывает ближайшие регионы. Это работает для CS2, Dota 2 и Deadlock.
  • «CS2: максимальный пинг поиска матча» не пускает поиск на далёкие сервера. OPEN предлагает значение по замеру: лучший пинг плюс запас. «Убрать лимит» возвращает поиск по умолчанию.

The Servers and ping block on the Games tab helps you play on the nearest servers.

  • Pick your country. OPEN shows which region to choose in Dota 2, Deadlock, Fortnite, Apex Legends and Rust.
  • Check ping measures ping to Valve servers right from your computer and shows the nearest regions. This works for CS2, Dota 2 and Deadlock.
  • CS2: max matchmaking ping keeps matchmaking off distant servers. OPEN suggests a value from the measurement: the best ping plus a margin. Remove limit restores the default matchmaking.

9ЗапретZapret

Вкладка «Запрет» обходит замедление и блокировку Discord и YouTube. Она работает на сторонней сборке zapret (Flowseal) с сетевым драйвером WinDivert.

  • Прочитайте предупреждение и нажмите «Понятно, продолжить».
  • Нажмите «Скачать модуль». Он скачивается с GitHub. Если GitHub недоступен, скачайте архив сами и нажмите «Указать папку».
  • Включите «Обход Discord и YouTube».
  • «Подобрать автоматически» перебирает стратегии и оставляет первую, при которой Discord и YouTube открываются. Стратегию можно выбрать и вручную, а «Проверить» покажет, работает ли текущая.
  • «Пауза для игр с анти-читом» выключает обход, пока запущены Valorant, League of Legends, FACEIT или ESEA.
  • «Свои сайты» открывает список, куда можно дописать свои домены.

Антивирусы часто помечают WinDivert как RiskTool или HackTool. Это не вирус, но если файлы модуля пропали, добавьте его папку в исключения. Включайте «Запрет», только если это не нарушает законы вашей страны и условия провайдера.

The Zapret tab gets around throttling and blocking of Discord and YouTube. It runs on the third-party zapret build (Flowseal) with the WinDivert network driver.

  • Read the warning and click Got it, continue.
  • Click Download module. It downloads from GitHub. If GitHub is unreachable, download the archive yourself and click Choose folder.
  • Turn on Discord and YouTube bypass.
  • Pick automatically tries strategies and keeps the first one that makes Discord and YouTube open. You can also pick a strategy by hand, and Check shows whether the current one works.
  • Pause for anti-cheat games turns the bypass off while Valorant, League of Legends, FACEIT or ESEA is running.
  • My sites opens a list where you can add your own domains.

Antivirus software often flags WinDivert as RiskTool or HackTool. It isn't a virus, but if module files disappear, add its folder to exclusions. Only turn Zapret on if doing so does not break the laws of your country or your provider's terms.

10СетьNetwork

Вкладка «Сеть» показывает, откуда берутся лаги: из домашней сети, у провайдера или на сервере игры. Работа идёт в три шага.

  • Шаг 1. Нажмите «Записать игровую сессию» и играйте как обычно. OPEN дважды в секунду мерит пинг до роутера, до интернета и до сервера игры и показывает, какие программы качают.
  • Шаг 2. «Тест нагрузки (15 с)» 15 секунд качает на полной скорости и смотрит, как растёт пинг. «Сохранить отчёт» записывает файл на рабочий стол.
  • Шаг 3. «Открыть профиль…» загружает файл профиля сетевых настроек. OPEN показывает каждое изменение и текущее значение. «Применить» применяет профиль, «Откатить профиль» возвращает всё как было.

Если пинг сильно растёт во время теста нагрузки, лаги идут от роутера. Помогает настройка QoS на роутере, а не твики Windows.

В отчёте нет IP-адресов, MAC-адресов и названий сетей Wi-Fi. Профиль меняет только то, что надёжно откатывается: свойства сетевой карты, её энергосбережение, TCP для подключения, DNS, MTU и раздачу обновлений Windows.

The Network tab shows where lag comes from: your home network, your provider or the game server. It works in three steps.

  • Step 1. Click Record a game session and play as usual. Twice a second OPEN measures ping to the router, the internet and the game server, and shows which apps are downloading.
  • Step 2. Load test (15 s) downloads at full speed for 15 seconds and watches how ping rises. Save report writes a file to the desktop.
  • Step 3. Open profile… loads a network settings profile file. OPEN shows every change and the current value. Apply applies the profile, and Revert profile puts everything back.

If ping rises a lot during the load test, the lag comes from the router. QoS on the router helps, not Windows tweaks.

The report has no IP addresses, MAC addresses or Wi-Fi network names. The profile only changes what reverts reliably: network card properties, its power saving, TCP for the connection, DNS, MTU and Windows update sharing.

11ПроизводительностьPerformance

  • «Компоненты» показывают в реальном времени загрузку и температуру процессора и видеокарты, память, видеопамять и скорость интернета.
  • «Игровые сессии» сохраняют после каждой игры средний FPS, 1 % low и время игры. Сессии короче 30 секунд не записываются. «Экспорт CSV» выгружает историю в таблицу.
  • «Анализ узкого места»: нажмите «Анализировать» во время игры. OPEN несколько секунд смотрит на загрузку процессора и видеокарты и говорит, во что упирается FPS, с советами.
  • «Бенчмарк (до/после)»: запустите игру, выберите длительность и нажмите «Замер «До»». Затем примените твики, вернитесь в то же место игры и нажмите «Замер «После»». OPEN покажет разницу в процентах.

Для честного сравнения делайте оба замера в одной и той же сцене игры, с одинаковыми настройками графики.

  • Components show live load and temperature of the processor and graphics card, memory, video memory and internet speed.
  • Game sessions store average FPS, 1% low and play time after every game. Sessions under 30 seconds aren't recorded. Export CSV saves the history to a spreadsheet.
  • Bottleneck analysis: click Analyze while playing. OPEN watches processor and graphics card load for a few seconds and tells you what limits FPS, with advice.
  • Benchmark (before/after): start the game, pick a duration and click Before run. Then apply tweaks, return to the same spot in the game and click After run. OPEN shows the difference in percent.

For a fair comparison, run both measurements in the same game scene with the same graphics settings.

12ИнструментыTools

  • «Обслуживание системы»: очистка временных файлов, кэша шейдеров DirectX, NVIDIA и AMD и освобождение памяти. Кэш шейдеров игры создадут заново, первые минуты игры могут быть чуть медленнее.
  • «Проверка на легальность» смотрит, не заблокирован ли доступ к путям, реестру и службам, которые проверяют анти-читы RP-серверов. Проверка ничего не меняет.
  • «Профиль NVIDIA (.nip)»: «Применить рекомендованный» или «Импортировать .nip…». Перед импортом OPEN сохраняет текущие настройки драйвера, «Откатить» возвращает их. Для этого нужен NVIDIA Profile Inspector в папке Assets\tools\npi рядом с OPEN.
  • «Системные команды» и «Ручные настройки» выключены по умолчанию. Кнопка «Оптимизировать всё» их не трогает, каждая включается отдельно.
  • System maintenance: clears temporary files, the DirectX, NVIDIA and AMD shader caches, and frees memory. Games rebuild their shader cache, so the first minutes of play may be slightly slower.
  • Legality check looks at whether access is blocked to paths, registry keys and services that RP server anti-cheats inspect. It changes nothing.
  • NVIDIA profile (.nip): Apply recommended or Import .nip…. OPEN saves the current driver settings before importing, and Revert restores them. This needs NVIDIA Profile Inspector in the Assets\tools\npi folder next to OPEN.
  • System commands and Manual settings are off by default. Optimize all leaves them alone; each one is turned on separately.

13СистемаSystem

  • «Точка восстановления»: создаёт точку восстановления Windows одной кнопкой.
  • «Частота монитора»: «Выставить максимум» включает самую высокую частоту, которую поддерживает монитор.
  • «Автозагрузка»: отключает программы из автозапуска без удаления записи.
  • DNS: выбор быстрого публичного DNS или автоматического, кнопка «Сбросить кэш».
  • «Удаление встроенного мусора»: удаляет выбранные встроенные приложения Windows. Их можно вернуть через Microsoft Store.
  • «Системные твики»: визуальные эффекты, фоновые приложения, таймер 0,5 мс, сетевая задержка, телеметрия и парковка ядер. Выключение твика возвращает значение Windows по умолчанию.
  • Restore point: creates a Windows restore point in one click.
  • Monitor refresh rate: Set maximum turns on the highest refresh rate your monitor supports.
  • Startup: disables programs from startup without deleting the entry.
  • DNS: pick a fast public DNS or automatic, plus a Flush cache button.
  • Remove built-in bloat: removes selected built-in Windows apps. You can get them back from the Microsoft Store.
  • System tweaks: visual effects, background apps, the 0.5 ms timer, network latency, telemetry and core parking. Turning a tweak off restores the Windows default.

14НастройкиSettings

  • Игровая автоматизация: «Авто-оптимизация при запуске игры», «Откатывать твики при выходе из игры» и «Усыплять фон на время игры». Фоновые программы не закрываются, а приостанавливаются и просыпаются после игры.
  • Оверлей: показывать ли его, показывать ли загрузку CPU и GPU, угол экрана и горячая клавиша («Задать клавишу»).
  • «Boost-режим процесса»: повышает приоритет игры и снимает с неё троттлинг EcoQoS в Windows 11.
  • «Запускать OPEN вместе с Windows»: через задачу планировщика с правами администратора, без запроса UAC при входе.
  • «Автоопределение любой игры»: OPEN ловит любую игру в полноэкранном режиме, а не только из списка.
  • «Доверенный режим» разрешает включать вместе настройки, которые конфликтуют друг с другом. Только для опытных.
  • «Резервная копия настроек» сохраняет все профили и настройки в один файл и восстанавливает их, например на другом ПК.
  • «Обновления»: «Проверить сейчас» и «Автоматически обновлять при запуске».
  • Язык интерфейса, окно «Что нового» и «Пользовательское соглашение». Смена языка требует перезапуска OPEN.
  • Game automation: Auto-optimize when a game starts, Revert tweaks when the game exits and Put background apps to sleep while gaming. Background apps aren't closed: they're suspended and wake up after the game.
  • Overlay: whether to show it, whether to show CPU and GPU load, the screen corner and the hotkey (Set key).
  • Process boost mode: raises the game's priority and removes Windows 11 EcoQoS throttling from it.
  • Start OPEN with Windows: through a Task Scheduler task with administrator rights, with no UAC prompt at sign-in.
  • Detect any game: OPEN catches any full-screen game, not just those on the list.
  • Trusted mode lets you turn on settings that conflict with each other at the same time. For experienced users only.
  • Settings backup saves all profiles and settings to one file and restores them, for example on another PC.
  • Updates: Check now and Update automatically at startup.
  • Interface language, the What's new window and Terms of Use. Changing the language requires restarting OPEN.

15Как вернуть всё и удалить OPENReverting everything and uninstalling

  • Твики: «Откатить всё» на Главной.
  • Настройки игр: «Откатить» в карточке игры или «Вернуть исходный файл» в редакторе.
  • Профиль сети: «Откатить профиль» на вкладке «Сеть».
  • Запрет: выключите обход. При выходе из OPEN обход и драйвер выключаются сами.
  • Профиль NVIDIA: «Откатить» на вкладке «Инструменты».

После этого удалите OPEN через «Параметры Windows → Приложения». Само удаление программы сделанные настройки не откатывает, поэтому сначала верните их.

  • Tweaks: Revert all on Home.
  • Game settings: Revert on the game card, or Restore original file in the editor.
  • Network profile: Revert profile on the Network tab.
  • Zapret: turn the bypass off. When OPEN exits, the bypass and the driver stop by themselves.
  • NVIDIA profile: Revert on the Tools tab.

Then uninstall OPEN from Windows Settings → Apps. Uninstalling does not by itself revert the changes, so put them back first.

16Частые проблемыTroubleshooting

  • Оверлей не показывает FPS. Запустите OPEN от администратора: кадры считываются через системные события Windows, без прав они недоступны. Оверлей работает в играх на DirectX.
  • Нет температуры процессора. Для неё нужен драйвер PawnIO. Загрузка процессора и все данные видеокарты работают без него.
  • Игра сбросила настройки. Изменения делались при запущенной игре или Steam. Закройте их, примените настройки снова.
  • «Запрет» не помогает. Нажмите «Подобрать автоматически». Если файлы модуля пропали, их удалил антивирус: добавьте папку модуля в исключения.
  • Антивирус ругается на OPEN. Скачайте установщик заново с официального сайта. Если предупреждение осталось, сообщите о ложном срабатывании через GitHub Issues.
  • The overlay shows no FPS. Run OPEN as administrator: frames are read from Windows system events, which aren't available without admin rights. The overlay works in DirectX games.
  • No CPU temperature. It needs the PawnIO driver. CPU load and all graphics card data work without it.
  • The game reset its settings. The changes were made while the game or Steam was running. Close them and apply the settings again.
  • Zapret doesn't help. Click Pick automatically. If module files disappeared, your antivirus removed them: add the module folder to exclusions.
  • Antivirus flags OPEN. Download the installer again from the official website. If the warning stays, report a false positive through GitHub Issues.
