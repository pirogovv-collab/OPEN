Windows, настроенная под игрыWindows, tuned for games

OPEN включает проверенные твики Windows, NVIDIA, сети и ввода, сам применяет профиль при запуске игры, настраивает игры изнутри и показывает FPS поверх игры. Каждый твик откатывается к прежнему значению.

OPEN turns on proven Windows, NVIDIA, network and input tweaks, applies a profile when a game starts, sets up games from the inside and shows FPS on top of the game. Every tweak reverts to its previous value.

ВозможностиFeatures

Десять вкладок, и что в каждойTen tabs and what's in each

OPEN не делает ничего скрытого. У каждой настройки написано, какой параметр она меняет и на какое значение, а исходное значение сохраняется до правки.

OPEN does nothing hidden. Each setting says which parameter it changes and to what value, and the original value is saved before the change.

ПресетыPresets

Что включает каждый пресетWhat each preset turns on

Пресет выбирается для каждой игры отдельно и применяется автопилотом при её запуске. Неизвестной игре, пойманной в полноэкранном режиме, достаётся «Баланс».

A preset is picked per game and applied by the autopilot when that game starts. An unknown game caught in fullscreen gets "Balanced".

Что именно меняет OPENExactly what OPEN changes

Все 18 твиков вкладки «Оптимизация»: ключ реестра, значение Windows по умолчанию и значение OPEN. «Нет значения» значит, что по умолчанию параметра нет, и откат его удаляет.

All 18 tweaks from the Optimization tab: the registry key, the Windows default and the OPEN value. "Not set" means the parameter doesn't exist by default, and reverting deletes it.

Твики NVIDIA пишутся в профиль драйвера и применяются, только если найдена видеокарта NVIDIA. Ключ сокращён, полный путь: HKLM\SYSTEM\CurrentControlSet\Control\Class\{4d36e968-e325-11ce-bfc1-08002be10318}\0000.NVIDIA tweaks go into the driver profile and apply only when an NVIDIA card is found. ИгрыGames

Какие игры OPEN знаетWhich games OPEN knows

Автопилот узнаёт эти игры по имени процесса и применяет пресет. Под названием стоит пресет по умолчанию, его можно поменять. Остальные игры ловятся по полноэкранному режиму, если включено автоопределение.

The autopilot recognizes these games by process name and applies a preset. The default preset is under each name and can be changed. Other games are caught by fullscreen mode when auto-detect is on.

«Редактор» — кнопка «Настройки игры»: все параметры из файла игры с понятными названиями, любое значение вручную и откат к исходному файлу. Опции запуска меняются при закрытом Steam, видеонастройки при закрытой игре: при выходе они перезаписывают свои файлы. Перед каждой правкой OPEN сохраняет копию файла.“Editor” is the “Game settings” button: every setting from the game file with clear names, any value by hand and a restore to the original file. Launch options are changed while Steam is closed, video settings while the game is closed, because on exit they overwrite their files. OPEN copies the file before every change.

БезопасностьSafety

Можно ставить на игровой ПКFine for a gaming PC

OPEN работает только с настройками Windows, драйвера и файлами настроек игр. В процессы игр он не лезет.

OPEN only works with Windows and driver settings and game config files. It stays out of game processes.

Замер FPS без внедренияFPS capture without injection

Кадры считаются по системным событиям Windows (ETW, провайдер Microsoft-Windows-DXGI), тем же способом, что у PresentMon. Кадр дольше 50 мс считается подфризом.

Frames are counted from Windows system events (ETW, the Microsoft-Windows-DXGI provider), the same way PresentMon does it. A frame longer than 50 ms counts as a stutter.

Откат точь-в-точьExact revert

Перед каждой правкой реестра OPEN запоминает старое значение. Перед правкой настроек Steam и игр делает копию файла. Парковка ядер помнит значения каждой схемы питания.

Before every registry change OPEN remembers the old value. Before changing Steam or game settings it copies the file. Core parking remembers the values of each power plan.

Без уязвимых драйверовNo vulnerable drivers

Температуры CPU читаются через подписанный драйвер PawnIO. Старый WinRing0, который Defender помечает как HackTool, убран.

CPU temperatures are read through the signed PawnIO driver. The old WinRing0, which Defender flags as a HackTool, is gone.

Проверка конфликтовConflict checks

Несовместимые настройки, например HPET и таймер 0.5 мс, нельзя включить вместе. Попробуйте в демо на вкладке «Система». Снять запрет можно доверенным режимом.

Settings that cancel each other out, like HPET and the 0.5 ms timer, can't be on together. Try it on the System tab of the demo. Trusted mode lifts this.

УстановкаInstall

От скачивания до первой игрыFrom download to first game

Установка занимает пару минут. Дальше OPEN обновляется сам.

Setup takes a couple of minutes. After that OPEN updates itself.

  1. Скачайте установщикDownload the installer

    Файл OPEN-Setup-0.7.5.exe лежит на странице релизов GitHub.

    OPEN-Setup-0.7.5.exe is on the GitHub releases page.

    Как пользоваться каждой вкладкой, написано в руководстве. Устанавливая OPEN, вы принимаете пользовательское соглашение.

    The user guide explains every tab. By installing OPEN you accept the Terms of Use.

  2. Запустите и разрешите права администратораRun it and allow administrator rights

    Без них OPEN не сможет менять системный раздел реестра и считать кадры. Если SmartScreen покажет предупреждение, нажмите «Подробнее» и «Выполнить в любом случае».

    OPEN needs them to change the system part of the registry and count frames. If SmartScreen shows a warning, click "More info" and "Run anyway".

  3. Выберите язык и пройдите авто-настройкуPick a language and run auto-setup

    OPEN определит процессор, видеокарту и память и предложит набор твиков. Вы смотрите список и подтверждаете.

    OPEN detects your CPU, GPU and memory and suggests a set of tweaks. You review the list and confirm.

  4. Сделайте замер «До» и «После»Measure "Before" and "After"

    На вкладке «Производительность» запустите бенчмарк в игре до оптимизации и после. OPEN покажет разницу в среднем FPS, 1% и 0.1% low.

    On the Performance tab, run the benchmark in a game before and after optimizing. OPEN shows the difference in average FPS, 1% and 0.1% low.

ВопросыFAQ

Частые вопросыCommon questions

Насколько вырастет FPS?How much FPS will I get?

Зависит от компьютера и игры, обещать конкретные цифры было бы нечестно. Чаще всего заметнее всего меняются 1% low и подфризы, а не средний FPS. Проверьте сами бенчмарком «до / после».

It depends on the PC and the game, so promising a number would be dishonest. Usually 1% low and stutters improve more than average FPS. Check for yourself with the before / after benchmark.

Меня не забанят?Can I get banned?

OPEN не внедряется в игры и не читает их память. Он меняет настройки Windows, драйвера и файлы графики игр, то же самое можно сделать вручную. Модуль «Запрет» на время Valorant, LoL, FACEIT и ESEA сам выключается.

OPEN doesn't inject into games or read their memory. It changes Windows, driver and game graphics settings, which you could change by hand. The Zapret module turns itself off during Valorant, LoL, FACEIT and ESEA.

У меня видеокарта AMD или Intel. OPEN подойдёт?I have an AMD or Intel GPU. Will OPEN work?

Да. Твики NVIDIA и импорт профиля драйвера просто пропускаются, всё остальное работает: Windows, сеть, ввод, игры, оверлей, замеры.

Yes. NVIDIA tweaks and the driver profile import are skipped; everything else works: Windows, network, input, games, overlay, benchmarks.

Как всё вернуть?How do I undo everything?

Кнопка «Откатить всё» на главной вернёт все твики к значениям, которые были до OPEN. Отдельный твик выключается своим переключателем. Удалённые встроенные приложения возвращаются через Microsoft Store, а для всей системы есть точка восстановления.

"Revert all" on Home returns every tweak to its value before OPEN. A single tweak is turned off with its own toggle. Removed built-in apps come back from the Microsoft Store, and there's a restore point for the whole system.

Как удалить OPEN?How do I uninstall OPEN?

Сначала нажмите «Откатить всё», затем удалите OPEN через «Параметры» → «Приложения». Если включали «Запрет», удалите модуль кнопкой на его вкладке.

Click "Revert all" first, then uninstall OPEN from Settings → Apps. If you used Zapret, remove the module with the button on its tab.

Оверлей не показывает FPSThe overlay shows no FPS

OPEN считает кадры по событиям DXGI. Игры, которые выводят кадры в обход DXGI (часть игр на OpenGL и Vulkan), могут не отображаться. Ещё проверьте, что OPEN запущен от администратора.

OPEN counts frames from DXGI events. Games that present frames without DXGI (some OpenGL and Vulkan games) may not show up. Also check that OPEN runs as administrator.

Как OPEN подбирает сетевые настройки?How does OPEN pick network settings?

На вкладке «Сеть» OPEN записывает пинг и трафик во время игры и делает тест нагрузки канала. По этому отчёту пишется профиль под конкретное подключение. OPEN показывает каждое изменение, применяет только то, что может надёжно вернуть, и откатывает всё одной кнопкой.

On the Network tab OPEN records ping and traffic while you play and runs a connection load test. A profile for that specific connection is written from the report. OPEN shows every change, applies only what it can reliably revert, and undoes everything with one button.

Можно выключить автообновление?Can I turn off auto-update?

Да, в «Настройках» в разделе «Обновления». Проверить вручную можно там же.

Yes, in Settings under Updates. You can also check manually there.

Как перенести настройки на другой ПК?How do I move settings to another PC?

В «Настройках» есть резервная копия: все профили, пресеты и настройки сохраняются в один файл и восстанавливаются из него. Облака нет.

Settings has a backup: all profiles, presets and settings are saved to one file and restored from it. There's no cloud.
